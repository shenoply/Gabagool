# Wet Whiskers

A small browser game. Pip's home floods overnight; scavenge the dumpster for what floated away and rebuild the rat house.

Play: https://shenoply.github.io/Gabagool/

Controls: WASD / arrows to move, E to grab, click to place, R to rotate. Touch controls on mobile.

Single file, no build step — Three.js r128 from CDN.
